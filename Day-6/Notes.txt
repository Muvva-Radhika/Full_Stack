CRUD operations in object
  Retrive: obj_name.key_name;
  Update:  obj_name.key_name=new_value;
          Insert a new key and value:  obj_name.new_key_name=value;
  Delete fields:
    delete obj_name.key_name;



    Object Inbuilt functions
      Object.keys() -> gets only key names in the object in the form of an array
      Object.values() -> only values as array
      Object.entries() -> both keys and values as 2d array  
          eg:  [[role:dev],[name:D],....]  
      Object.seal() -> can't insert or delete any fields but we can update the values
           to check whether the object is frozen then use console.log(object.issealed());
      Object.freeze() -> can't insert,update or delete the values into object
          to check whether the object is frozen then use console.log(object.isfrozen());
